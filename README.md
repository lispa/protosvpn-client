# ProtosVPN

A VPN client for Windows and Linux for use with your own OpenVPN and VLESS servers. Import `.ovpn` files and `vless://` links, select profiles, and manage them in one place. The interface supports English and Russian.

> **Development preview:** VPN connections are not implemented yet. This version supports profile import and management only. Profiles are stored in memory and removed when the application closes.
