# ProtosVPN

VPN-клиент для Windows и Linux для работы со своими OpenVPN- и VLESS-серверами. Позволяет импортировать `.ovpn`-файлы и ссылки `vless://`, выбирать и управлять профилями. Интерфейс — на русском и английском.

> **Предварительная версия:** VPN-подключение пока не реализовано. Доступны импорт и управление профилями. Профили хранятся в памяти и удаляются при закрытии приложения.
